# 无名杀技能编写教程

这是一份写给**玩家**的教程。

它要解决的问题只有一个：

> **你脑子里有一个技能的点子，怎么把它变成游戏里真能用起来的东西？**

如果你曾经想过"要是我能自己设计一个武将就好了"，或者"这个技能要是能改成那样就好了"，这份教程就是为你写的。

---

## 一、你不需要会编程

这句话请认真读一遍：**你不需要事先会编程。**

这份教程假定你：

- 会玩三国杀（知道什么是体力、手牌、判定、出牌阶段……）
- 会用电脑，会新建文件夹、会复制粘贴文件
- 除此之外，**什么都不需要会**

代码里的每一个新名词，我们都会解释。解释一次不够就解释两次。你可能在某一段会遇到"这行字是什么意思"，别急，往下读，或者往回翻 —— 这很正常，学写代码本来就是这样反复来回的过程。

---

## 二、你需要准备什么

1. **一台装好了无名杀的电脑。**
2. **一个能编辑纯文本的编辑器。** 系统自带的记事本就能用，但更推荐 [VS Code](https://code.visualstudio.com/)（免费，能高亮代码、少犯低级错误）。
3. **耐心。** 真的，这条最重要。第一次做的时候一定会出错，出错是正常的，不是你的问题。

> ⚠️ 有一个小坑要提前说：**别用 Word、WPS 这类软件**编辑代码文件。它们会偷偷往文件里塞格式信息，游戏会读不懂。一定要用记事本或代码编辑器。
>
> 另外，保存文件时要注意**编码选 UTF-8**（大多数编辑器默认就是，不用管；如果你用记事本，保存时留意右下角的编码）。

## 三、怎么读这份教程

不同的人有不同的需求，你可以按自己的情况选一条路线：

### 路线 A：我就想赶快做出一个技能（最短路径）

按这个顺序读：

**第 1 章 → 第 2 章 → 第 3 章 → 第 4 章**

读完这四章，你就能做出一个"到某个时机自动做某件事"的技能了 —— 这可是技能里最大的一类。

### 路线 B：我想系统地学（推荐）

从第 1 章顺着往下读。**基础篇 10 章**，把技能框架搭起来；之后是**进阶篇**，把机制一个个补全。每一章都建立在上一章的基础上。

### 路线 C：我卡住了，技能没反应

直接跳到 **第 31 章 · 排错手册**。那一章把所有常见的"为什么没反应"都列出来了，按症状查就行。

## 四、全书约定

为了让这份教程好读，我们用几个固定的小标记：

| 标记 | 意思 |
| --- | --- |
| 代码块左上角的文件名 | 这段代码该写在哪个文件里 |
| ❗ | 容易出错的地方，看到它请放慢速度 |
| ⭐ | 关键结论，值得记下来 |
| 「」 | 括住的是技能名或牌名，比如「闭月」「杀」 |
| ` ` | 括住的是代码，比如 `player.draw()` |

**每一章末尾都有「动手改一改」**，是一两个小练习，让你把这一章学的东西用一遍，后面附有参考答案。

> **强烈建议你动手做练习。**
> 看别人写代码和自己在键盘上敲一遍，效果差了十倍不止。而且很多坑，只有自己踩过一次才会记住。

## 五、这份教程会带你做什么

我们会虚构一个武将，叫**演练**（群势力，4 点体力，称号"纸上谈兵"）。

然后，一章一章地，给他添加技能。等到全书读完，他会拥有 7 个各具特色的技能，涵盖了你写技能时会用到的绝大部分套路：

| 技能 | 描述 | 教什么 |
| --- | --- | --- |
| 初演 | 准备阶段，你可以摸一张牌。 | 最基础的技能长什么样 |
| 砺锋 | 当你造成或受到伤害后，你可以摸一张牌。 | 时机怎么选（这里有坑） |
| 演武 | 出牌阶段限一次，你可以弃置一张手牌，令一名角色摸一张牌。 | 主动发动的技能 |
| 拟攻 | 你可以将一张手牌当【杀】使用或打出。 | "视为使用某张牌"的技能 |
| 问策 | 当你受到伤害后，你可以弃置一张手牌，然后摸两张牌。 | "自己问玩家"与"取消＝不发动" |
| 筑台 | 锁定技，你的手牌上限+2。 | 持续生效的效果 |
| 积势 | 限定技，出牌阶段，你可以弃置一张手牌，获得2枚「势」。你每有1枚「势」，你的手牌上限+1。 | 标记、子技能、限定技 |

> 顺便说明一下：真实设计里，一个武将 3 个技能左右就很充实了。这里给演练塞了 7 个，纯粹是为了教学方便 —— 让我们能一直回到同一个武将身上加东西，而不用每章换一个新角色。
>
> **进阶篇会怎么做？** 从第 11 章起换一套讲法：先把引擎的"工具箱"（全局对象与角色方法）讲透，再**新开一个武将「践行」**，把拼点、判定、武将牌上的牌、失去技能、觉醒技这些进阶机制**一个一个做成它的技能** —— 和「演练」正好构成"纸上谈兵 → 纸上躬行"的对照。
>
> **不要以为技能越多越好。** 新手最常见的毛病就是给武将堆一大堆技能，结果每个都不好玩。

每当我们写一个新技能，都会拿一个**官方现成的技能**做对照。比如写「初演」的时候，我们会去看官方的「闭月」是怎么写的 —— 你会发现它们几乎一模一样。这样你就能确信：自己写的东西，和游戏里跑的东西，是同一个套路。
